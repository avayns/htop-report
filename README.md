#Генератор Markdown-отчетов о пакетах (Задание 1)

Скрипт pkgreport.sh автоматически скачивает .deb пакет, анализирует его содержимое и генерирует подробный Markdown-отчет.

## Что делает скрипт:
1. Проверяет наличие необходимых утилит в системе.
2. Скачивает пакет с помощью apt-get download.
3. Генерирует ASCII-баннер с названием пакета (с помощью figlet).
4. Выводит информацию о пакете (версия, зависимости и т.д.), форматируя ключи жирным шрифтом.
5. Выводит структуру файлов пакета (с помощью tree).
6. Проверяет и выводит скрипты мейнтейнера (preinst, postinst, prerm, postrm), если они есть.
7. Сохраняет итог в файл <имя_пакета>.md.

## Зависимости
Для работы скрипта требуются утилиты: `figlet`, `tree`, `dpkg-deb`, `apt-get`.
Если их нет, установите командой:
```bash
sudo apt install figlet tree dpkg apt
